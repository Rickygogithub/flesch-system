このシステムを作ったきっかけ

もともとは、アルト記号がまともに読めなかったのを克服するために、読譜のフラッシュカードを作ろうとしたのが始まりです。

続き

ヴァイオリンは長く弾いていましたが、ヴィオラを始めたのは50歳を過ぎてからで、ト音記号は問題なくても、アルト記号の読譜にはかなり苦労しました。作っているうちに「視唱やリズム練習もあるといいな」「聴音もあれば」「調弦の確認もあれば」「主音を鳴らしながら音階や分散和音を鳴らせるようにしよう」「純正律とピタゴラスの違いを実感できるような和音モードと音階モードを作ってみよう」などと機能が増えていき、気づけば6つのツールになりました。教育プログラムとして設計されたものではなく、自分の練習の必要に応じて、その都度作り足してきたものです。

音律の考え方は、カール・フレッシュの音程理論（旋律はピタゴラス音律、和声は純正律）を軸にしています。60歳を過ぎてからアプリ制作を始めた、いわゆる「バイブコーディング」（生成AIとの対話で実装する方法）によるもので、理論的な誤りや実装の不具合に、後から気づいて直すことも度々あります。もし気づいた点があれば、教えていただけると助かります。

ヴァイオリンとヴィオラの両方に対応できるよう、基本的にはト音記号・アルト記号の両方を切り替えられるようにしています。ただし、聴音の低音モード（A=221基準）など、ヴィオラの低い音域に合わせた内容も一部含まれているので、その点はご了承ください。

自分の練習の記録・道具箱として置いているだけのものですが、同じような訓練に関心のある方の参考になれば、それも嬉しく思います。スマホでも使えますが、PCや音質の良いオーディオでの使用をおすすめします。実際の演奏では、先生の指導を優先してください。ここでの音程はあくまで理論から導いたガイドラインです。

1〜5は抽象的な訓練用の音符・音型を使いますが、6のOrchestra Excerptだけは、実際のオーケストラ・レパートリーから抜き出した難所を教材にしています。

楽器を持って練習する時間だけでなく、通勤・通学など楽器を持てない隙間時間に、読譜・聴音・リズム・視唱の練習をするのも効果的です。特に、Integrated Performance Practiceでフレッシュの音階や7和音をアプリの音に合わせて歌う練習は、音程感覚と和声感覚を結びつける上で効果を感じています。

🔇 音が出ない場合のチェックリスト

iOS（iPhone・iPad）の場合

  1. マナーモード（消音スイッチ）を確認
    iPhoneの側面スイッチがオレンジになっていたら解除してください
  2. 端末の音量を確認
    音量ボタンでメディア音量が上がっているか確認してください
  3. Safariの自動再生設定
    設定アプリ → Safari → 自動再生 →「すべてのメディアを許可」に変更してください
  4. Bluetoothデバイスの確認
    イヤホン・スピーカーが接続されている場合は、そちらから音が出ていないか確認してください
  5. 着信・通話・タブ切り替え後に音が止まる場合
    画面をタップしてから再度お試しください（iOS 26でのAudioContext問題に対応済みですが、まれに発生することがあります）
  6. ホーム画面追加アプリとして使用している場合
    アプリスイッチャーから完全に閉じて、再度開いてください
  7. 低電力モードがオンの場合
    設定 → バッテリー → 低電力モードをオフにしてお試しください

Androidの場合

  1. マナーモード・サイレントモードを確認
    通知パネルから解除してください
  2. メディア音量を確認
    着信音量とは別に、メディア音量を上げてください

共通

  1. ブラウザを再読み込み
    ページをリロードして、画面をタップしてから再度お試しください
  2. 別のブラウザで試す
    Safari・Chrome・Edgeなど別のブラウザでお試しください

練習システムの概要

大きく2つの系統があります。

① 頭の中で音楽を作る（ソルフェージュ）

  • Score Reading：読譜（単音・和音・度数・調号）
  • Melody Dictation Trainer：視唱・リズム・聴音

② 音程を作る

「正確な基準を作る → その基準で耳を育てる → 複雑な状況でも保てるか試す」という順で使っています。

  • Pure Intonation Tuner：開放弦を正確に合わせる（基準づくり）
  • Beautiful Intonation Training：その開放弦との共鳴を頼りに、1オクターブ・長三和音・短三和音という最小単位で耳の基準を作る
  • Integrated Performance Practice：3オクターブ・7和音・重音・転調といった複雑な状況の中で、その基準を保てるかを試す

楽器の練習は長年してきましたが、楽器を持たずに頭の中で音楽を作り、体に明確な指示を出すソルフェージュの訓練は、ほとんどしてきませんでした。これを2ヶ月ほど続けたことと、Integrated Performance Practiceで楽器を弾くだけでなく階名で歌う練習をしたことで、指板上のマッピングができるようになり、演奏が大きく変わりました。この2つの系統は、どちらも欠かせない柱だと感じています。

  • 歌唱でも、音階・7和音とも下降の方が上昇より難しいと感じる。楽器演奏における下降の困難さ（右手が体から遠ざかる、指の順序が逆になるといった身体運動的な要因）とは異なり、歌唱の場合は身体運動の制約がほとんどないため、原因も別のところにあるようだ。一つは単純に、下降で歌う経験の絶対量が上昇より少なく、慣れていないこと。もう一つは、7和音の下降が、根音から見て完全4度上（第7音）から始まるため、歌う前にまずその出発点の音を正確にイメージすること自体が難しいこと。上昇であれば、一番安定した基準音である主音からそのまま歌い始められるが、下降では、主音から離れた、相対的に不安定な音から歌い始めなければならず、想起のハードルが一段上乗せされているように感じる
  • 弓元から1/4の位置を持ってそれより元側だけで弾く練習では、ハイエルボーになり背筋がきつくなる。通常の弾き方でも腕の重み自体は変わらないはずなので、これは普段の保持が不十分だということにならないか、と考えた。ただし、キツさを決めるのは重さそのものではなく、関節の角度によって決まるトルク（重さ×腕の長さ×角度による係数）であり、通常の姿勢は上腕が体に近い角度にあるためトルクが小さく、そもそもそこまで大きな力を要求されない。「保持していない」というより、「保持する必要性が低く、支持筋群が働きにくい姿勢になっている」と理解する方が正確なようだ
  • また、ハイエルボーになることで、重力を利用して腕の重みを弦にかけることができなくなり、肘から先（前腕・手首）を能動的に使って圧力とスピードを作らざるを得なくなる。これは、腕の重みに頼らずスピード・接触面積で音を作るという、これまでの方針を身体的に強制する構造になっている
  • この2点を踏まえると、この練習はオーバーロードトレーニングとして意味を持つと考えられる。ハイエルボー姿勢によって、通常は要求されない負荷を肩甲帯の支持筋群（三角筋、僧帽筋、菱形筋、広背筋など）に意図的にかけている。重量そのものを増やすわけではなく、不利な角度によってトルクを増大させているという点で、一般的な筋トレの負荷増強とは性質が異なり、演奏中の姿勢保持に近い、等尺性・準等尺性の筋持久力トレーニングと位置づけられそうだ。演奏で必要なのは瞬間的な最大筋力ではなく、長時間にわたり姿勢を微調整しながら保持し続ける持久的な制御力であり、この負荷特性は演奏の文脈に合っている
  • 厳しい条件で支持筋群を鍛え、かつ肘から先を能動的に使う感覚を作った直後に通常の姿勢へ戻ると、支持筋群には相対的な余力が生まれ、肘から先の能動性もそのまま持ち越される。大きな筋肉が土台を安定させ、指先まではしなやかに動く、という分業ができた状態で通常のボーイングに戻れるのではないか
  • なお、オーバーロードトレーニングには本来「刺激→回復→適応」というサイクルが必要であり、この負荷の高い姿勢を長時間続けると、支持筋群の回復が追いつかず、疲労や炎症のリスクが高まる可能性がある。短時間・限定的な取り入れ方にとどめ、実施後の肩・首まわりの張りや違和感の有無を、体からのフィードバックとして注視しておきたい
  • チャイコフスキーの弦楽セレナードで、元弓で細かい音符を弾く箇所を練習しているとき、弓元1/4を持ってそれより元で弾く練習は、軌道の最適化・身体の使い方に加えて、弓の配分そのものを鍛える効果もあると再認識した。使える弓幅が全体の1/4程度に制限される上、実際の演奏では使わない本当の弓元数センチは、松脂の乗りも悪く、そこに弓が行かないよう避けながら弾く必要があるため、実質的に使える範囲はさらに狭い。この限られた範囲の中で、音符ごとに必要な弓の長さを正確に配分しなければ音符として成立せず、軌道・身体の使い方と並ぶ、もう一つの重要な効果になっているようだ
  • また、弓幅が極端に小さいと、移弦による弓と弦の接点の位置の変化が、相対的に大きな意味を持つようになる。駒からの距離（弦に対して垂直方向、音質に関わる）は、弦ごとに素早く変えられる調整ではないため、全ての弦にある程度対応できる妥協点（最大公約数的な距離）を探ることになる。一方、C線はA線より体から見て数センチ左側にあり、それだけで弓先寄りになるため、弓幅が極端に小さい状態では、弦を移るたびに弓をどれだけ元に持ってくるか（A線であればその逆）を意識的に調整する必要が生じる。普段、弓の真ん中から先を使っているときはここまでシビアな調整は必要ないが、弓幅が極端に狭いこの練習では、こうした配分・位置の最適化がコントロールに非常に有効に効いてくるようだ
  • 重音の練習は、ローポジションの方が指の開きが大きく難易度が高い上、曲での頻度も高いので、そういう調性を優先して選ぶことにした。単音の3オクターブ音階・7和音は、ハ長調のみ下降から上昇するパターンで練習した
  • カンパニョーリで、下降を意識しつつ、不要な重みを載せないこと、弓元で軌道が狂わないことを意識して弾いたところ、弓元で音が途切れにくくなった。これまで理論的に検討してきた「重みに頼らない」「軌道を保つ」という考え方が、別の教材でも実際に効果を発揮することを確認できた
  • 重音でも、弓を指板側へ傾ける奏法を使ったところ、これまでスカスカな音しか出なかったところが、まともな音が出るようになった。今日発見した弓の傾きが、重音の音質改善という具体的な成果に直結した

  • 短く持つ練習で音が出ないことがよくあるのは、手首から先の能動的な動きや指弓の問題である以前に、より根本的には弓の軌道が崩れていることが原因のようだと気づいた。基本は、コマからの距離を意図的に変えない限り一定に保つこと、弓を駒と平行に動かすこと。音が出なくなる時は、これが崩れている。弓元では肘が大きく曲がり、てこの原理で重くなった圧力を相殺するために弓をやや指板側に傾けるのが基本だが、その傾ける動作に、腕を伸ばす動きが連動して入り込んでしまい、それが軌道を崩しているのではないか。腕の重みを乗せるという意識があると、肘を曲げた状態から本能的に伸ばそうとする動作が入りやすいのかもしれない
  • さらに、この軌道の崩れの背景には、弓を肩の回転に合わせて動かすと本来は楕円状の軌道を描いてしまう、という構造があるのではないかと思い至った。それを直線的な軌道に補正するために、初心者の段階でまず「手を体から遠ざける意識を持つ」と習う。しかし弓元では、肩の回転による楕円の影響がそもそも小さいため、この「遠ざける」意識はさほど必要ない。それにもかかわらず、この意識を弓元でも過度に働かせてしまっていることが、先述の「傾ける動作に腕を伸ばす動きが連動してしまう」現象の一因になっているのかもしれない
  • 対策として、弓元に来た時、弓を若干手前に引くような意識を持ったところ、軌道が修正され、手首から先の能動的な動きも自然にできるようになった。この意識づけが実際の筋肉の動きを正確に説明しているかどうかは重要ではなく、結果として軌道が整い、動きも改善したことが重要だと考えている
