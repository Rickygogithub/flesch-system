🎻 Flesch System

アマチュアのヴィオラ／ヴァイオリン奏者による、自分用の練習ツール置き場

このシステムを作ったきっかけ

もともとは、アルト記号がまともに読めなかったのを克服するために、読譜のフラッシュカードを作ろうとしたのが始まりです。

続き

ヴァイオリンは長く弾いていましたが、ヴィオラを始めたのは50歳を過ぎてからで、ト音記号は問題なくても、アルト記号の読譜にはかなり苦労しました。作っているうちに「視唱やリズム練習もあるといいな」「聴音もあれば」「調弦の確認もあれば」「主音を鳴らしながら音階や分散和音を鳴らせるようにしよう」「純正律とピタゴラスの違いを実感できるような和音モードと音階モードを作ってみよう」などと機能が増えていき、気づけば6つのツールになりました。教育プログラムとして設計されたものではなく、自分の練習の必要に応じて、その都度作り足してきたものです。

音律の考え方は、カール・フレッシュの音程理論（旋律はピタゴラス音律、和声は純正律）を軸にしています。60歳を過ぎてからアプリ制作を始めた、いわゆる「バイブコーディング」（生成AIとの対話で実装する方法）によるもので、理論的な誤りや実装の不具合に、後から気づいて直すことも度々あります。もし気づいた点があれば、教えていただけると助かります。

ヴァイオリンとヴィオラの両方に対応できるよう、基本的にはト音記号・アルト記号の両方を切り替えられるようにしています。ただし、聴音の低音モード（A=221基準）など、ヴィオラの低い音域に合わせた内容も一部含まれているので、その点はご了承ください。

自分の練習の記録・道具箱として置いているだけのものですが、同じような訓練に関心のある方の参考になれば、それも嬉しく思います。スマホでも使えますが、PCや音質の良いオーディオでの使用をおすすめします。実際の演奏では、先生の指導を優先してください。ここでの音程はあくまで理論から導いたガイドラインです。

1〜5は抽象的な訓練用の音符・音型を使いますが、6のOrchestra Excerptだけは、実際のオーケストラ・レパートリーから抜き出した難所を教材にしています。

楽器を持って練習する時間だけでなく、通勤・通学など楽器を持てない隙間時間に、読譜・聴音・リズム・視唱の練習をするのも効果的です。特に、Integrated Performance Practiceでフレッシュの音階や7和音をアプリの音に合わせて歌う練習は、音程感覚と和声感覚を結びつける上で効果を感じています。

🔇 音が出ない場合のチェックリスト

iOS（iPhone・iPad）の場合

  1. マナーモード（消音スイッチ）を確認
    iPhoneの側面スイッチがオレンジになっていたら解除してください
  2. 端末の音量を確認
    音量ボタンでメディア音量が上がっているか確認してください
  3. Safariの自動再生設定
    設定アプリ → Safari → 自動再生 →「すべてのメディアを許可」に変更してください
  4. Bluetoothデバイスの確認
    イヤホン・スピーカーが接続されている場合は、そちらから音が出ていないか確認してください
  5. 着信・通話・タブ切り替え後に音が止まる場合
    画面をタップしてから再度お試しください（iOS 26でのAudioContext問題に対応済みですが、まれに発生することがあります）
  6. ホーム画面追加アプリとして使用している場合
    アプリスイッチャーから完全に閉じて、再度開いてください
  7. 低電力モードがオンの場合
    設定 → バッテリー → 低電力モードをオフにしてお試しください

Androidの場合

  1. マナーモード・サイレントモードを確認
    通知パネルから解除してください
  2. メディア音量を確認
    着信音量とは別に、メディア音量を上げてください

共通

  1. ブラウザを再読み込み
    ページをリロードして、画面をタップしてから再度お試しください
  2. 別のブラウザで試す
    Safari・Chrome・Edgeなど別のブラウザでお試しください

練習システムの概要

大きく2つの系統があります。

① 頭の中で音楽を作る（ソルフェージュ）

  • Score Reading：読譜（単音・和音・度数・調号）
  • Melody Dictation Trainer：視唱・リズム・聴音

② 音程を作る

「正確な基準を作る → その基準で耳を育てる → 複雑な状況でも保てるか試す」という順で使っています。

  • Pure Intonation Tuner：開放弦を正確に合わせる（基準づくり）
  • Beautiful Intonation Training：その開放弦との共鳴を頼りに、1オクターブ・長三和音・短三和音という最小単位で耳の基準を作る
  • Integrated Performance Practice：3オクターブ・7和音・重音・転調といった複雑な状況の中で、その基準を保てるかを試す

楽器の練習は長年してきましたが、楽器を持たずに頭の中で音楽を作り、体に明確な指示を出すソルフェージュの訓練は、ほとんどしてきませんでした。これを2ヶ月ほど続けたことと、Integrated Performance Practiceで楽器を弾くだけでなく階名で歌う練習をしたことで、指板上のマッピングができるようになり、演奏が大きく変わりました。この2つの系統は、どちらも欠かせない柱だと感じています。

このほかに、実際のオーケストラ曲の難所を教材にした Orchestra Excerpt を、実験的に作っているところです。

📝 日々の練習で気づいたこと（随時アプリの改良に反映）

2026年8月24日

  • 昨日の「弓の重み＋αで十分、元弓ではむしろ持ち上げる」という気づきを、数値と力学の面から整理し直した。弓の重さはヴィオラでおよそ70g前後、弦を正しく鳴らすのに必要な圧力はおよそ10〜150g程度とされ、弓自体の重さだけで、必要な圧力の範囲をほぼカバーしている。一方、腕1本の重さは3kg台（体重の約5%程度）で、必要な圧力の20倍以上にあたる。「腕の重みを乗せる」という指導を文字通り行うと、必要量を大きく超えてしまうことになる
  • 弓元で「弓だけでも重くなる」のは、てこの原理によるとの見解を持った。弓の重心（バランスポイント）はフロッグから全長の1/3ほどの位置にあり、弓元で弾くときは、この重心が支点（手）から先端方向に大きく離れた、長いてこの腕として働く。そのため、弓自身の重さだけで、接触点（弓元）に既に十分、あるいは過剰な圧力がかかる。先端に向かうほど、支点と接触点の距離が縮まり、弓自身の重さによる自然な圧力は減っていくため、これを補うために前腕を回内させ、筋肉の力で圧力を足す必要が出てくる
  • さらに、弓の中央部分で必要な圧力が少ないのは、てこの効果が中立に近いことに加え、弦の振動（弓の返しのように速度がゼロになる瞬間と違い）がすでに安定して持続しているため、振動を保つのに必要な力そのものが小さくて済む、という理由も重なっていると考えた
  • 先端に向かうにつれて腕が伸び、それに伴い手首の角度が元弓のときとは逆方向に変化していくことが、回内という動きを、意図的な操作である以上に、腕の構造上、自然に引き起こしていると感じた
  • ボウイングには、圧力の増減以外にも、重みをコントロールする手段があり、これは元々実行していたことだと気づいた。弓元では弓を指板側に傾け（毛の接触量を減らして音を軽くする）、先端に向かうに従って垂直〜駒側に近づけていく。また、弓元では小指で弓の重さを支えて弦にかかりすぎないようにし、先端に向かうに従って、その役割が人差し指に移っていく。フレッシュの「ヴァイオリン奏法」にも、緩く持っただけでは弓元は重すぎ、先端は軽すぎ、中央でのみ弓自身の重さで音が出る、という記述があり、そのため先端は人差し指で押し下げ、弓元は少し持ち上げる、という一致した説明になっていることを確認した
  • これらを踏まえると、「腕の重みを乗せる」よりも「重みをコントロールする」という表現の方が適切だと考えた。重みは、乗せる（増やす）だけでなく、元弓では減らす、先端では足す、傾きで接触量を変える、という増減両方向の連続的な調整であり、圧力・スピード・接触点（サウンディングポイント）という音作りの主要素からすれば、重みはその一部でしかない
  • さらに、「脱力して腕の重みを乗せる」という表現も見直した。脱力というと、常に重みをかけていて持ち上げる動作が入っていないように聞こえるが、実際には、重みをコントロールするために、持ち上げる・弓を運ぶ・傾きを調整するといった動作に、常に筋肉を使っている。「脱力」が本来意味すべきは、力を使わないことではなく、必要な筋肉は能動的に使い、使うべきではない筋肉（不要な力み・硬直）は使わない、ということだと理解し直した

2026年8月23日

  • 「腕の重みを乗せる」とよく言われるが、実際には弓の重み＋αほどで必要な圧力は十分にかかる。むしろ、そこから意識を向けるべきは「腕の重みを減らす、持ち上げる」方向ではないか。特に元弓では、弓の重さ−αくらいまで意識的に軽くする必要がある。右肘を思い切って高く上げ、腕の重みを（乗せるのではなく）減らす方向にコントロールしたところ、弓元で音が途切れる現象がなくなった。奏法理論のpronation（内旋）・supination（外旋）は、この現象と同じ動きを指しているが、あくまで前腕の回転運動としての記述であり、「なぜそれをするか＝重みの引き算のため」という解釈までは踏み込んでいない。動きの名前と、その目的の理解は別物だと感じた
  • スピッカートも同様で、弾く瞬間よりも、弓が宙に浮いている間にいかに腕を持ち上げているかが重要だと感じた。特に、上げ弓・下げ弓それぞれの最上点を「どの高さに」「弓のどの位置（元寄りか先寄りか）に」持っていき、そこで「どの程度止める（滞留させる）か」を意図的に設計することが、跳ねの質を決めているのではないか。一般的な指導は「弓は自然に跳ねるので脱力して任せる」という受動的な説明が多いが、2つの最上点を能動的にデザインする、という捉え方の方が、実際にコントロールする上では有効だと感じた

2026年8月22日

  • 澤野立次郎「基礎から実習 ソルフェージュ」を階名で視唱した後、ヴィオラで答え合わせをする際に、記譜より1オクターブ下げて弾く練習が、指板のマッピング強化に非常に有効だと気づいた。実際の音域で弾くと、楽譜を見た時点で指の位置が自動的に出てきてしまうが、C線・G線で1オクターブ下を弾こうとすると、階名を意識して押さえ直す必要が出てくる。この、自動化されていない部分こそが、これまで弱かったマッピングであり、そこを直接鍛えられる
  • 移弦やポジション移動の際、途中で意識を切らず、間の音も（ポルタメント的に）頭の中で鳴らしながら移動すると、動きがスムーズになることに気づいた
  • ビブラートも、最高音・最下音・間の音・かける速さを明確に頭でイメージしながらかけると、音楽的な表現になることを発見した

2026年8月16日

  • フレッシュ7和音を5度圏に沿って和音を鳴らしながら全ての調で歌唱し、続けてピタゴラス音階を平行調ペアで2オクターブ歌唱、その後主音だけを鳴らしながら同主調の音階と7和音を続けて歌う、という3段階のプロトコルを実践。和声の機能的な移り変わり、調号の瞬時の判定、そして最も負荷の高い同主調の統合という、難易度の段階的な上昇になっている
  • 同主調の調号は「短3度上げた長調で判定する」という計算方法を確立（例：ハ短調→変ホ長調で♭3。ヘ短調→変イ長調で♭4）。フラットが7個以上になる手前（変ホ短調→変ト長調、♭6）で理論上の意味を失うため、そこで打ち止めとする
  • 平行調では、長調を歌い終えた直後に短調の旋律が自然に浮かぶようになってきた。同主調でも、視覚的な手がかりなしにウォーキングをしながら調号を計算できるようになってきた
  • Score Readingの調号判定モードに属調・下属調を追加する際、「5度上に進むと♯が1つ増える（あるいは♭が1つ減る）」という5度圏の規則そのものをあらためて正確にコード化する必要が生じた。この作業を通じて、属調・下属調の関係が単なる暗記対象ではなく、5度圏の構造、そして調号の数の増減という原理から直接導き出せることへの理解がさらに深まった

2026年8月15日

  • フレッシュ7和音を、長調のみでなく同主調（短調）とも対比させて練習すると、和声的な重心の感覚がさらに深まる。まず短三和音（例：c-es-g）と長三和音（c-e-g）を歌い、長調・短調の響きの違いを確認してから7和音に入ることで、その後の和音の移り変わりをより丁寧に味わえる。1つの和音を最後まで丁寧に歌いながら、次の和音も頭に思い浮かべておくことで、「移り変わりを楽しむ」という質的な変化が生まれる
  • 音階を平行調ペアで歌う際、長調を歌い終えた直後に平行短調の旋律が自然に浮かぶことが増えてきた。これはScore Readingの調号判定訓練による瞬時の認識と、音階を指折り数えながら平行調ペアで歌う訓練による実際の発声への変換、両方の成果が統合された結果だと考えられる

2026年8月14日

  • フレッシュ7和音の主音（ドミソ／ドミラ／ドファラ…）を、機械的な度数の組み合わせとしてではなく、主音の位置そのものが調ごとに移り変わっていく、和声的な重心の移動として意識すると、和音の安定感の変化として体感できる。3度・4度の識別が自動化された調では、あえてそちらへの意識を薄め、和声的な機能（属七・減七から主和音への解決など）に意識をシフトさせる
  • 2オクターブ音階を、Integrated Performance Practiceの5度圏の順（長調→平行短調のペア）で歌唱していると、ある調の後、次の調（例：B durの後、g moll）が意識せずに口から出るようになってきた。平行調の関係そのものが、想起ではなく反射として機能し始めている兆候
  • Score Readingアプリを使った調号判定のトレーニングは、単独の瞬発力としては優先順位が低いと以前判断していたが、判断を修正。調号から調性を素早く特定できることは、全ての調性を長調・平行短調のペアにした音階の歌唱・練習を支える基盤になっており、その観点では優先順位を上げるべきだった

2026年8月13日

  • ロングトーンで音が鳴っている間、脳内でも音を鳴らし続ける必要があるのと同様に、スピッカートで弓が弦から離れている（音が鳴っていない）間も、脳内に音楽的なイメージ（余韻など）を保ち続ける必要がある。接触と接触の間の「無音」を、内的には空白にしない
  • 「弓の機能にお任せする」という奏法でも、意識を完全に手放すと、お任せ自体ができなくなる。弓の自律的な動き（弾力性・重力）を信頼しながら、その動きが正しく続くように、絶えず微細な修正を加え続ける必要がある
    • 弓を振り子のように使い、最下点が弦との接点、上が腕の運動が反転するタイミングのイメージ。どこまで持ち上げてどこで止める（返す）とスムースになるかを意識すると改善がありそう
  • カンパニョーリの課題箇所で、ポジション移動がスムーズにいかない原因は、左腕に力が入っていたこと。力を抜くと、腕がスッと適切な位置に動き、角度も自然に変わる
